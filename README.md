The World in One Day — 26 November 2026: a 1024×1024 newspaper front page summing up the day's world news in one image. The lead story is the Houthis' claimed strike on Saudi Arabia's Ras Tanura refinery, with five further panels — the Cairo tanker fire, the Mississippi plane crash, the Hera images of asteroid Dimorphos, Pakistan's first astronaut reaching Tiangong, and the freed Cartagena hostages — plus an "Also today" footer strip. All stories were researched from real reporting of 26 November 2026 (Reuters, AP, AFP, ESA).

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only) copies the shipped `entry.png` to the output directory given by `MAKEFUN_OUTPUT_DIR` (or `./output`).
